Add exactly 500 new public scientific-software repositories selected by reproducible random sampling from a bounded GitHub search union. Scanner evidence only; no blind ratings or external-validity claims. Requested by Fernando Paladini.

- Analysis baseline: `ce37e4151bb9ea7349da5afa17b4d393dfbc8fd1`, 3186 entries; Showcase baseline: `686edb4345d20f296b839a0e5789bd71d41847d5`, 3228 repository-version records across 3207 repositories.

- Category draw: seed 20261011, shortlist geospatial-software, cybersecurity-products, iot-and-embedded-software, scientific-computing-and-bioinformatics, education-and-learning-software, selected scientific computing and bioinformatics.
- Discovery: 47 bounded GraphQL topic searches across 24 scientific topics; 4601 returned records and 4142 unique canonical IDs. Results are a bounded search union, not a global ranking.
- Random sample: xorshift32 Fisher-Yates seed 1760233997 over 3662 eligible new candidates; stars are recorded provenance and do not affect Harness Score or sample order.
- Every selected project is public, non-fork software. Pins and README/implementation blob evidence were verified against the selected commit; no repository code is executed.
